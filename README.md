# 日日英文 · English Studio

A browser-based English practice app with a Traditional Chinese interface.

- Dictionary definitions and question–answer examples
- Manual ChatGPT diary correction and simple Spanish translation workflow
- English and Spanish text-to-speech, copy buttons and shadowing
- Three American English voice choices where supported by the device

No AI API key or backend is required. Diary text is processed in the browser and is not saved after refreshing. Dictionary lookups use Wiktionary. Voices depend on the device; microphone access is optional for recording practice.

## GitHub Pages

Publish the `main` branch from the repository root in Settings → Pages. All assets use relative URLs, so project pages work without a build step.
